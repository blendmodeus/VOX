# VOICEPRINT QUICK START

## What is VOICEPRINT?

VOICEPRINT traces how a creator's voice evolves through time. It's not an AI detector—it's a revelation engine that shows how a person's mind has moved through years of content.

**Think of it as a "spiritual EKG" of someone's online presence.**

## Quick Start (5 Minutes)

### 1. Install Dependencies

```bash
pip install -r agents/voiceprint/requirements.txt
```

### 2. Basic Usage

```python
from agents.voiceprint import VOICEPRINT_instance

# Analyze a creator
result = VOICEPRINT_instance.analyze_creator(
    creator="naval",
    sources=["twitter", "blog"],
    date_range=("2015-01-01", "2025-01-01")
)

# Get voice timeline
timeline = result.get_timeline()

# Get voiceprint signature
signature = result.get_signature()

# Identify shifts
shifts = result.get_shifts()
```

### 3. View Results

```python
# Interactive timeline
timeline.visualize()

# Voiceprint radar chart
signature.visualize()

# Shift map
shifts.visualize()
```
